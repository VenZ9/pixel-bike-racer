# Pixel Bike Racer 🏍️

A 2D pixel-art arcade motorcycle racing game built with **Godot 4** and designed primarily for Android.

The game takes visual inspiration from classic arcade racing games, with a rear-view motorcycle, desert environments, long roads, collectible coins, opponents, bike upgrades, and a clean pixel-art interface.

## 🎮 Features

- 2D pixel-art arcade motorcycle racing
- Rear-view racing perspective
- Desert racing environment
- Multiple motorcycles with different statistics
- Garage system
- Bike purchasing system
- Bike upgrade system
- Acceleration upgrades
- Speed upgrades
- Handling upgrades
- Engine upgrades
- Coin collection
- Distance-based coin rewards
- Quest system
- Opponent/knockout system
- Bike color customization
- Free color presets
- Unlockable custom colors and gradients
- Speedometer
- Distance counter
- Coin counter
- Settings menu
- Theme settings
- Sound settings
- Control settings
- Keyboard controls
- Touch controls
- Local save system
- Dynamic motorcycle engine audio
- Android APK builds through GitHub Actions

## 🔧 Upgrade System

### Acceleration

Five upgrade levels:

- Level 1: +2
- Level 2: +5
- Level 3: +8
- Level 4: +11
- Level 5: +14

### Speed

Five upgrade levels:

- Level 1: +8 km/h
- Level 2: +10 km/h
- Level 3: +12 km/h
- Level 4: +14 km/h
- Level 5: +16 km/h

Total possible speed upgrade bonus: **+60 km/h**

### Handling

Five upgrade levels:

- Level 1: +2
- Level 2: +4
- Level 3: +6
- Level 4: +8
- Level 5: +10

### Engine

Each upgrade:

- Engine stat: -5
- Maximum speed: +1 km/h

Five engine upgrades are available.
